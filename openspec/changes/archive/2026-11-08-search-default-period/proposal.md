# Proposal

## Why

Прогон 2026-11-06 в LM Studio (`google/gemma-4-e4b`) на вопрос «когда я
последний раз стригся?»:

- модель не стала искать, а попросила у пользователя период — `from` и `to`
  у `search_operations` обязательны, а вопрос «когда последний раз» периода
  не имеет;
- на «в этом году» подставила `to: 2026-09-29` при сегодняшнем 2026-11-06.

Причина второго — LM Studio не передаёт модели `instructions` MCP-сервера: в
чистом чате на «какое сегодня число?» модель ответила заглушкой
«[Текущая дата]», хотя первая строка `instructions` — «Сегодня …». Описания
инструментов модель видит, `instructions` — нет. Дату знает сервер, и
просить её у модели не нужно.

## What Changes

- `from` и `to` у `search_operations` необязательны: без `to` — сегодня в
  поясе `MCP_TZ`, без `from` — с начала истории. В ответе `period.from: null`,
  если `from` не задан (наружу не показываем техническую дату `1900-01-01`).
- Описание инструмента: для «когда последний раз / когда впервые» период не
  задавать.
- Остальные инструменты не меняются — их период несёт смысл вопроса
  («в сентябре»), значение по умолчанию там скорее навредит.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `wallet-tools`: период `search_operations` по умолчанию.

## Impact

- `src/tools.cpp` (схема, `search_period`, эхо), тесты, README.
- Правок в других сервисах нет: wallet-report принимает любой период.
- Отдельно (не в этом change): перенести остальные правила из `instructions`
  в описания инструментов — `instructions` LM Studio не видит.
